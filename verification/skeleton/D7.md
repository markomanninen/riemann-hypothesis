# The record D7 opened in full

An object of the record type `D7` is one bundle of number-theoretic data with the equations
that tie its pieces together. It has 141 fields, and 282 definitions of the project lie below
it on eight levels. This document says what the fields hold, group by group, lists the numbers
and bounds that the definitions fix, and gives one reading for each of the 282 definitions.

`D7` matters because lines 6 to 22 of the outline of the proof, which [`README.md`](README.md)
defines, state results about a `D7` datum. [`GLOSSARY.md`](GLOSSARY.md) shows this for the
definition `BundleCondition`. When the script follows the names that `D7` uses, it stops after
eight levels and 282 definitions. Their Lean text holds about 127,000 characters, which fits
into one run of the model, so each reader had all 282 definitions in view at once.

The readings were written by a language model and checked by further runs of the same model.
No mathematician has checked them.

## How the readings were made

[`d7.py`](d7.py) follows the definitions that the text of `D7` names, then the definitions
that those name, until no new definition appears, and writes all of them into one file with
their whole text. Level 1 holds the 45 definitions that `D7` names, and the levels below hold
96, 62, 38, 23, 10, 5 and 3.

Four kinds of runs of the command line tool Claude Code read that file, each in a folder that
held only the file and, for a check, the readings to be checked. The briefs are the four files
of [`briefs/`](briefs/) whose names start with d7.

1. A first reader and a second reader each wrote a reading of every definition. Each run had
   the whole file in view and wrote the readings of about 40 definitions, so one reader took
   seven runs.
2. A check compared both readings of every definition with its Lean text. It found two errors
   in the first readings, in the definitions 82 and 241, and 13 errors in the second readings
   of eleven definitions. This document prints the first readings. The two wrong first
   readings were replaced by the corrected text that the check supplied, and the second
   readings served only for the comparison.
3. A first and a second reader each wrote what an object of `D7` is as a whole, with its
   fields divided into groups and with a list of the numbers that the definitions fix.
4. A check compared the first of those with the Lean text. Each of the 141 fields lies in
   exactly one of 23 groups. The check found two errors, one about which quantity the field
   `gat_d` constrains and one where the reading gave a meaning to names that have no body in
   the file. Both sentences were corrected. They are the sentence about `gat_d` in the group on
   good primes and the sentence about `loc_tie` in the group on tie conditions.

## Limits

- The count of 282 follows the names that the declaration graph of the README links to a
  text. A name that is reached through a dot after a value, as `r` is in `R.r`, is missing
  from the count, and so is everything of the Mathlib library. The script therefore stops
  where such names begin, and the base below `D7` is larger than 282. The readings mark 88
  names as unopened in 53 definitions, for example `Ranks.r`, `Ranks.nV` and `Ranks.N`.
- The first reader, the second reader and the checks are the same language model, so they can
  share a blind spot that a check does not find. The corrected sentences were not checked a
  second time.
- A reading says what a definition is. It does not say what the definition is for in the proof.
- The list of numbers is the list of the first reader of the whole. The second reader listed
  further conditions, so the list is not complete.
- What a reading reports as a suggestion from the names is a guess.

## What an object of D7 is

An object of D7 is one large bundle of number-theoretic data together with the equations that tie the pieces to each other. It starts from integer parameters (a Ranks record R), a CM number field setting (a Host record with fields E and F, primes q, d, g 0, g 1, pde, pde' and a finite set of level primes), and families of Hermitian spaces over E. It then adds a second number field LL with its places and a finite set of words. There is one rational parameter record for each word and each element of a set Tau of size f, and each word also has a member made of column data, data at a prime T and a period map. On top of this it adds a determinant group Dt with characters that fix the values rhoDet and rhoDet', p-adic period rings for every prime l, a large package of Galois-representation and automorphic data (the N-stage records), Hermitian lattice forms, Haar measures on the groups U(P,Q), theta-jet data at chosen primes, and local data at good primes. Many of the fields are conditions that make these independently given pieces agree, and the group sections below say which fields hold data and which hold conditions.

The next sentences are a suggestion from the names, which the Lean text does not show. As a suggestion only, the names hint that D7 is the full set of hypotheses for one step of a large argument, the step named in its module RhoDetPrimeEqMuTildeMulChiPow, which writes the column values rhoDet and rhoDet' as values of characters on a determinant group. The names Host, cmType, Psi and condN suggest a CM field with a CM type and a conductor, and the period-ring names (Ainf, Bcris, BdR, LocTied) suggest Fontaine's p-adic Hodge theory. The N-stage names (heckePol, frobEig, IsCrysW, csd and the Speh-style sums) suggest Galois representations attached to conjugate self-dual automorphic representations of unitary groups. The names ThetaJet, HCParam and CDHaar, together with the Hermitian lattices, suggest theta lifts and harmonic-analysis estimates, but the file gives no bodies for many of these names, so these readings remain guesses.

## The 141 fields in 23 groups

### Ranks, host field, spaces and volumes

The 5 fields are `R`, `host`, `sp`, `vol`, `vol_pos`.

R is a Ranks record of natural numbers k, m, t (k and m even, t odd, 2 ≤ m, m + 3 ≤ k, k + m − 1 + 5 ≤ t, 3m < t, m ≤ 2·ord ≤ k and m² ≤ k + m(t + 1)). host is a Host record over R that supplies a CM number field E together with two number fields that the code calls F and K, primes q and d, a number QS, two distinct level primes g 0 and g 1, two further level primes pde and pde' that leave remainder 1 on division by 15, and an ideal ccK. The field sp is a Spaces record over E, meaning a CM extension E over a totally real F of degree 2, a prime T, and Hermitian spaces X j, X', Y j, W j and V j over E with prescribed ranks, embeddings and signatures. The function vol gives each Hermitian space a real number, and vol_pos requires that number to be strictly positive.

### Row data and the base parameters

The 3 fields are `what₂`, `eTau`, `hc`.

what₂ is a Rows.Data record over R. It holds a field LL with an embedding embLL into the complex numbers and a system of places, a finite set Tau with exactly f elements, finite-dimensional complex inner product spaces such as EE (with Drows = (1 − delp)·Dall and delp ≤ 1), a type Word, and spaces Mu u, Amb μ and Mt μ j with lattices and self-adjoint idempotent operators. eTau is a bijection between Tau and a set the code calls R.Psi. hc assigns to each τ in Tau an HCParam record, which is a list u of k half-integers, a list v of k − 1 integers and lists b and e of m integers that interlace (v i < u i and u (i+1) < v i, and −b 0 < u (k−1)), with e j − b j ≥ (t + 3)/2 and b (j+1) − e j ≥ (t + 3)/2.

### Words and their parameters and members

The 10 fields are `wordFin`, `u₀`, `hcW`, `hcW_base`, `hcW_v`, `hcW_b`, `hcW_e`, `hcW_first`, `hcW_last`, `mem`.

The set of words is finite, and u₀ is a chosen base word. The function hcW gives one HCParam record for each word u and each τ, and it agrees with hc at the base word. For every word the entries v, b and e are the same as those of hc, and so are the first entry u 0 and the last entry u (k−1) when k > 0, so only the inner entries of u may change from word to word. For each word, mem u is a Member made of three parts, a column chain C (finite class sets cls i with finite stabilizer groups whose orders divide a positive number DGam, values rhoDet and rhoDet' of absolute value 1 for i < m, and integers sSharp and sDiv given by the functions sExp' and sExp at e i and i + 1, which this reading takes to be e i − N(i+1)/2 and e i − N(i)/2), a ColumnsAtT record A (a prime T, a set vT of f elements, finite fields Fv of size T, nontrivial additive characters, a positive Dstar and a number GamP > 1) and a period map P.

### The field LL

The 5 fields are `nfLL`, `starLL`, `tcLL`, `galLL`, `starLL_cx`.

LL is a number field, that is a finite extension of the rational numbers, and it carries an involution called star. LL is totally complex and is a Galois extension of the rationals. The embedding embLL into the complex numbers sends star x to the complex conjugate of embLL x.

### Hermitian lattice data over LL

The 2 fields are `div`, `div_good`.

div is a DivData record over LL indexed by the words. It consists of a Hermitian lattice RR, one lattice Nu u per word, linear maps Bk u from Nu u into the dual of RR, real numbers h u, HH, etaF and delP, and a natural number Dall, with delP ≤ 1 and HH at least the rank-weighted average of the differences between mu (Nu u) and h u plus RR.muMax. div_good requires that every matrix X v attached to RR and to each Nu u at each infinite place v has a determinant that is a unit, so that it is invertible.

### Embedding the host field into LL

The 9 fields are `embE`, `embE_φ₀`, `conjF`, `conjF_eq`, `embE_conj`, `LL0`, `hostField_le_fixedField`, `O_int`, `O_contains`.

embE is a ring homomorphism from E to LL whose composite with embLL is the chosen complex embedding host.φ₀ of E. conjF is an F-linear field map of E equal to the map the code calls host.conj, and embE turns host.conj into star. LL0 is a subfield of LL that contains the image of E. Every element of the ring what₂.O maps to an algebraic integer of LL, and the image of every algebraic integer of E is hit by some element of what₂.O.

### Places of LL

The 4 fields are `plEq`, `val_eq`, `ram_eq`, `conj_val`.

plEq is a bijection between the abstract places of what₂ and the nonzero prime ideals of the ring of integers of LL. For nonzero x, the valuation at a place w equals the w-adic order of x, defined as minus the logarithm of the multiplicative valuation (vAdd). The stored ramification index at w equals the ramification index of the prime over the integers (eWL), and the valuation of x at the conjugate place equals the valuation at w of star x.

### The prime T of each word

The 10 fields are `T_level`, `T_norm`, `sp_T`, `cOf`, `cOf_ne`, `cOf_eq`, `T_win`, `GamP_eq`, `T_ne_pde`, `Dstar_eq`.

For each word u, the prime T(u) of its member lies in the level primes of the host, and it equals π times host.conj π for an algebraic integer π of E lying in K with π − 1 divisible by QS·q·d·(g 0·g 1)². The prime of the spaces sp is T(u₀), and for each word there is a nonzero c in E with c·conj(c)·T(u) = T(u₀). Each T(u) lies between Tstar and (1 + 1/(f·k))·Tstar, where Tstar is a quantity the code calls (mem u).A.Tstar. GamP is the same for every word, T(u) differs from pde and from pde', and Dstar equals what₂.Dstar.

### Lattices for the column classes

The 2 fields are `clsLat`, `clsLat_lat`.

For each word u, each level i and each class c in cls i, clsLat gives a submodule over the ring of integers of E inside the space (sp.X i).V. clsLat_lat requires each of these to be a full lattice in that E-vector space, in the sense of Submodule.IsFullLattice.

### Identifications with period data

The 11 fields are `eMu`, `eMt`, `perCol_base_eq_PtilCol`, `Bu_linL`, `Bu_linR`, `chTw`, `memberColumns_twistedChain_base`, `e0Tw`, `PTw`, `eMtTw`, `perCol_tie`.

eMu u is a complex-linear isomorphism from what₂.Mu u to a space the code calls Mram, and eMt u is a complex-linear isomorphism from the space Mt of the period map to Amb at the base tuple mu0. At the base tuple the pairing perCol equals a map the code calls PtilCol, read through these isomorphisms, and the pairing Bu is linear in each argument. For each tuple μ there is a twisted column chain chTw u μ that equals the member's chain at mu0, with linear isomorphisms e0Tw and eMtTw and a period map PTw. For μ different from mu0, perCol is again PtilCol of PTw, read through these identifications.

### Bases matching LL lattices with complex spaces

The 6 fields are `jEE`, `jEE_basis`, `jN`, `jN_basis`, `Dall_eq`, `delP_eq`.

jEE is an additive map from the LL-space of RR into EE that is semilinear with respect to embLL, meaning jEE(a x) = embLL(a)·jEE(x). It sends the basis of RR to a basis of the complex space EE, and in the same way jN u sends the basis of Nu u to a basis of Mu u. The numbers Dall and delP of div agree with Dall and delp of what₂.

### Determinant group and its characters

The 15 fields are `Dt`, `instDt`, `detCls`, `muTil`, `chiD`, `UO`, `chiD_UO`, `e1Dt`, `rest_detCharacter_on_unitary_eq`, `relDet`, `relDet_self`, `relDet_mul`, `relDet_smul`, `rhoDet_eq_inv_muTilde_chiD_pow`, `rhoDetPrime_eq_muTilde_mul_chi_pow`.

Dt is a commutative group, detCls sends each class to Dt, muTil n and chiD are homomorphisms from Dt to the nonzero complex numbers, and chiD is trivial on a subgroup UO. e1Dt maps the unitary elements z of E (those with star z · z = 1) to Dt, and chiD(e1Dt z) is the product over τ in Tau of the inverse of host.emb(eTau τ)(z). For self-dual lattices in E^N (finitely generated, spanning, and equal to their dual for the form sum of star(x i)·y i), relDet gives an element of Dt/UO that is 1 on equal lattices, multiplies along chains L, L', L'' and equals the class of e1Dt(det γ) when L' is the image of L under a unitary matrix γ. Finally rhoDet i c equals muTil(i+1) of detCls to the power −1 times chiD of detCls to the power −⌊N(i+1)/2⌋, and rhoDet' i c equals muTil(i+1) of detCls times chiD of detCls to the power ⌊N(i)/2⌋.

### Positive weights on Tau

The 2 fields are `dsig`, `dsig_pos`.

dsig gives a real number for each element of Tau. dsig_pos requires every one of these numbers to be strictly positive.

### Cusp-span data

The 5 fields are `s`, `s_split`, `s_HH`, `s_Cu`, `s_PlF`.

s is an SData record built from R, F, E, conjF, the words, Tau and hcW. It holds a positive rational Del with consecutive v entries differing by exactly 4·Del, an injective letter map from words to sequences of k − 2 booleans with u(l+1) = v l − 1/2 − Del when the letter is true and v l − 1/2 otherwise, a finite-dimensional complex inner product space HH with spaces Cu u and maps into it, positive volumes, terms and pairs, and local field data atP at each prime of F with a degree 2 extension. The split datum at p is present exactly when the residue characteristic of p is g 0 or g 1, HH has complex dimension what₂.Dall, Cu u is linearly isomorphic to the member's space Mu0, and the places PlF correspond bijectively to the nonzero primes of the ring of integers of F.

### Local p-adic period theory

The 3 fields are `loc`, `locA`, `locT`.

loc gives a LocPrime record for every prime l. That is a pair of rings B and BdR with Galois actions, a Frobenius map φB, an element tB, a character χQ, period data for every finite extension of the l-adic numbers, compatible l-power roots of unity ζQ, and valuations normalised by v(l) = 1. For each l, locA adds actions on the completed algebraic closure and on its tilt, an element ε built from roots of unity, and an injective map from A_inf into B that respects the Galois action, Frobenius and the filtration. locT identifies B and BdR with the rings Bcris and BdR that the project builds from Witt vectors of the tilt, compatibly with the l-adic integers, the Galois actions, Frobenius, the filtrations, an element t that is a logarithm of the Teichmüller lift of ε, and A_inf.

### Galois and automorphic stage data

The 9 fields are `nd`, `ntw`, `naut`, `nbc`, `nexp`, `ntypes`, `nStage_trivialCharacter_compat`, `nStage_trivialCharacter_coeff_eq`, `nth`.

nd is an NData record. It holds an algebraic closure Om of E and a set Loc of local indices i, each with a prime l i, a level j i with 1 ≤ j i ≤ m, and a complete discrete valuation ring O i finite over the l-adic integers. It also holds a local Hecke algebra acting faithfully on a free module, characters chi i c equal to chi i 1 times the cyclotomic character to the power −(c − 1) for 1 ≤ c ≤ t, sets S i and Q i of split places, sets PlG k of size f with monic labels of degree r, and the identity restRowsFiniteGroupCard = ∏ over k of |GL_r(ℤ/g k)|^f. ntw (NTw) gives twisting data with characters delta whose inertia image has exactly 15 elements at auxiliary places of norm ≡ 1 mod 15, naut (NAut) gives abstract local parameters with dimension, sums, twists and Frobenius eigenvalues together with automorphic objects CG a, nbc (NBC), nexp (NExp) and nth (NTh) give base-change, expansion and theta data, and ntypes (NTypes) gives an abelian extension Mray of K unramified outside primes dividing QS·q·d, with g k ≡ 1 mod QS·q·d and multisets bc with sum of a·d equal to r. The two remaining fields require a condition that the code calls ntypes.IdempotentMatchesAction and require embLL(eLL0 g) to equal the coefficient at g of an element the code calls ntypes.e0.

### Local bridges at primes above l

The 5 fields are `nbr`, `nbr_ind`, `self_good`, `ntwbr`, `ntwbr_ind`.

For each local index i and each prime w of E above l i, nbr gives a LocBridge. That is a finite extension Kw of the l-adic numbers in which E is dense, an embedding j of Om into the algebraic closure of the l-adic numbers, a continuous isomorphism between the decomposition group at w and the Galois group of Kw, and a larger extension LL containing all conjugates of Kw whose ring of integers is isomorphic to O i. nbr_ind requires x to lie in the valuation ring at w exactly when |j x| ≤ 1, and self_good requires every root of unity whose order divides lcm(l, host.condN) to lie in that LL. ntwbr and ntwbr_ind give the same kind of bridge, with the same condition, for the twist indices and the rings O0.

### Tie conditions between stages

The 7 fields are `loc_tie`, `bc_tie`, `rbar_tie`, `mtpar_tie`, `Z_tie`, `Zgood_tie`, `etaJ_tie`.

The field loc_tie requires that iotaOQ agrees with the bridge map toLL, and that the NAut predicates the code calls IsCrysW, IsdRW and IsPotCrysW and the jump multisets jumpsW agree, through the local bridges and loc, with the bridge notions the code calls IsCrysW, IsdRW, IsPotCrysW, IsJumpW and multW and with their versions IsCrysE, IsdRE, IsPotCrysE, IsJumpE and multE over larger finite extensions. bc_tie requires bc σ to equal the multiset of pairs (a, d) for any matching parameter list whose automorphic pieces satisfy a condition the code calls csd and an integrality condition, and rbar_tie requires rbar to be semisimple with characteristic polynomials that reduce correctly. mtpar_tie requires MtPar to be the span of the matching typeV spaces, and Z i and Zgood i equal the explicitly defined sets ZN and ZgoodN (points whose parameter list contains the part (1, muC i twisted by etaTinv, t)). For 1 ≤ j ≤ m, etaJ_tie requires etaJ j w to equal the sum of a quantity the code calls nd.etaLoc over the local indices with level j and place w.

### Hermitian forms of members and isometries

The 10 fields are `fm`, `eMu_isom`, `nuIn`, `nuIn_inj`, `nuIn_range`, `nuIn_jN`, `nuIn_norm`, `jEE_norm`, `s_Cu_isom`, `sEE`.

fm u is a MemberForms record for member u. It holds vector spaces of dimension N i over the fields Fv, dominant integer weights lam given by an explicit formula from hc, Hermitian lattices lat i over LL embedded in the class-function spaces with matching norms, and nonnegative reals beOn and thFree. The inner product on Mu u equals a form the code calls ipC 0, read through eMu, and the same holds for Cu u through s_Cu. nuIn u is an injective LL-linear map from the lattice space of Nu u into the space of lat 0, with image a subspace the code calls ramSub, compatible with jN and eMu, and preserving the coordinate norm normAt at every infinite place, while jEE preserves norms at the infinite place of embLL and sEE is a conjugate-linear isometric embedding of EE into s.HH.

### Haar measures on unitary groups

The field is `cd`.

cd is a CDHaar record giving a Haar measure on each group U(P,Q) of complex matrices preserving the form with matrix diag(1 for P entries, −1 for Q entries). The measure on U(N,0) is a probability measure. For each P and Q there is one constant c, neither 0 nor infinite, that is the limiting density near the identity of both cd P Q and cd (P+Q) 0 against a Lebesgue-normalised measure on the Lie algebra.

### Theta-jet sites

The 13 fields are `jet`, `jetU`, `jetL`, `jetL'`, `jetW`, `jetW_l`, `jetTau`, `jetW1`, `resChar_thetaJetPlaceDegOne`, `jetTau1`, `jetU1`, `jetL1`, `jetL1'`.

jet is a ThetaJet record with sites of two kinds. A site of the first kind carries a prime l ≥ 5, an even d ≥ 2, ranks N0 = N(jOf − 1) and N1 = N(jOf) with 1 ≤ jOf ≤ m, and a power series in variables indexed by ℤ/d × {0..N0−1} × {0..N1−1}, and a site of the second kind has d replaced by 1, the host class of l equal to the inert class, and a condition HNeZero that fails. For each site of the first kind the fields choose a word, a class at level jOf − 1 and a class at level jOf of that word's chain, a place of LL whose residue characteristic is the site's prime l, and a map from ℤ/d into Tau. Sites of the second kind get the same choices, with one element of Tau instead of a map.

### Extra global data and local data at good primes

The 3 fields are `gx`, `gat`, `gat_d`.

gx is a GlobalExtra record giving strictly positive reals Om τ s and thOne s for each τ and each complex embedding s of LL. For each word u and place w whose residue characteristic p satisfies GIdx (p prime, p ≥ 5, inert class, HNeZero, p not a level prime and p not dividing T(u)), gat gives a GAtP record at p, which is a discrete valuation ring with fraction field, place data satisfying HidaSetting, and a number e. The field gat_d requires a quantity named d to equal the complex dimension of the member's space Mu0. The file gives no body for this d, and d is a different number from the field e of GAtP.

### Signature of the spaces Y j

The field is `Y_sigval`.

For every j ≤ m and every complex embedding τ of E, the signature of the Hermitian space sp.Y j at τ is the pair sigYD R j. That pair is (rankY j − ⌊(m − j)/2⌋, ⌊(m − j)/2⌋), where rankY is a rank the code calls R.rankY.
