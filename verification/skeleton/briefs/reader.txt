Do not search the web and do not open the source code.

You may add what a name suggests, in a separate field, marked as a suggestion.
3. Write for a reader who knows undergraduate mathematics and no Lean. Explain a symbol when you use it.
4. Write full sentences. Use no colons and no semicolons in the prose fields.

Return one JSON array and nothing else, with one object per dossier, in the order of the line numbers:

{

 "why": one sentence that gives the reason for that confidence
}
