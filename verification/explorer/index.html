How to read this page

The submission proves the Riemann Hypothesis from allChi, which says that no Dirichlet L-function vanishes for Re s > 1/2. The proof of allChi is the theorem everyCharacter in the module at the top of the tree, and 175,174 project modules lie below it.

The tree is the dominator tree of the import graph. A module B sits under a module A when every chain of imports from the top down to B passes through A. A branch therefore holds the modules that only its top module needs, and its size measures how much of the proof that module alone accounts for. A module that several branches reach by separate routes sits higher up, under their common dominator, and at the top level these shared modules make up most of the source.

The tree is built from import lines only. A module listed here may still go unused by the proof terms. Which declarations the proof really uses will follow from the declaration graph of the Comparator export.

Red markers name metaprogramming found by a text search of the module. The theorem and definition counts come from the same search.
